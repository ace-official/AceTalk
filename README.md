## ⚡ Features

* **Direct P2P Architecture:** Powered by PeerJS, establishing a direct connection between peers without intermediary servers.
* **Instant File Sharing:** Transfer files securely and directly across the peer connection.
* **Custom Statuses:** Set and update personalized user statuses on the fly.
* **Sleek Interface:** Clean, distraction-free UI designed for speed and simplicity.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
* **Networking:** PeerJS / WebRTC
